# Glaido ба дуут бичилтийн зах зээлийн судалгаа

**Огноо:** 2026-08-13 · **Зорилго:** Monspeech-д нэмэх/сайжруулах зүйлийг тодорхойлох

---

## 1. Товч дүгнэлт

Glaido бол Monspeech-тэй **яг ижил асуудлыг** шийддэг апп: hotkey дарж ярихад курсор
дээр цэвэр текст орно. Гол ялгаа нь ганцхан зүйл дээр:

> **Glaido болон 2026 оны бүх өрсөлдөгч дуу → текстийн ДАРАА LLM тавьдаг.**
> Monspeech тавьдаггүй.

Тэд үүнийг «AI auto-edit» гэж нэрлэдэг: «ааа», «тэгээд тэгээд» гэх чигчлүүрийг
хаяж, «5 цагт... үгүй ээ 6 цагт» гэсэн өөрийгөө засахыг ойлгож эцсийн хувилбарыг
нь үлдээж, ямар аппад бичиж байгааг хараад өнгө аясыг тааруулдаг. Google-ийн
буулгасан түүхий текст болон LLM-ээр цэвэрлэсэн текстийн ялгаа нь өнөөдрийн зах
зээлийн үнийн шалтгаан (сард $17–20).

**Гэхдээ Monspeech тэднээс хурдан** (0.26 сек vs Aqua-гийн 450 мс, Glaido хугацаагаа
хэлдэггүй), **үнэгүй**, **бүртгэлгүй**, **монгол хэлээр эхэлсэн**. Эдгээрийг
алдалгүйгээр LLM давхаргыг нэмэх арга бий — 5-р бүлгийг үзнэ үү.

**Хамгийн үнэ цэнэтэй 5 санаа (эрэмбэлсэн):**

| # | Юу | Яагаад | Хүчин чармайлт |
|---|---|---|---|
| 1 | LLM цэвэрлэгээ — **хоёр шатаар** (түүхийг нь эхлээд буулгаад, дараа нь солих) | Зах зээлийн гол ялгаа. Хурдаа алдахгүйгээр авах боломжтой | Дунд |
| 2 | Танигчийг **залгуур (provider) болгох** | Google-ийн задгай эндпойнт SLA-гүй — нэг өдөр хаагдана. Мөн ElevenLabs-ыг A/B хийх боломж нээгдэнэ | Бага |
| 3 | **Аппаар ялгах горим** (Mode / профайл) | `winfocus.py` цонхны нэрийг аль хэдийн мэдэж байгаа — бэлэн суурь | Дунд |
| 4 | **Агент горим** — Hermes гүүрийг апп руу оруулах | `tools/monspeech_hermes_bridge.py` нь Glaido-гийн Agent Mode-ын 80% нь аль хэдийн бэлэн | Дунд |
| 5 | **Дуугаар засах** («сүүлийн өгүүлбэрийг устга», «жагсаалт болго») | Aqua-гийн гол давуу тал. `deliver(text, backspaces)` механизм бэлэн байгаа | Дунд |

## 2. Glaido — задаргаа

**Юу вэ:** macOS (эх), 2026-06-29-нээс Windows 11. Electron биш, native.

**Ажиллах загвар:** hotkey дарж барих → ярих → тавих → курсор дээр текст.
Push-to-talk, тасралтгүй бичлэг, агент дуудах гурвыг тус тусын товчинд оноож болно.
Menu bar-т сууна, вэб хяналтын самбартай.

**Онцлогууд:**

| Онцлог | Тайлбар | Monspeech-д байгаа эсэх |
|---|---|---|
| Дурын аппад бичих | Gmail, Slack, GitHub, Notion, Telegram, Cursor, Claude, Figma… | ✅ байна |
| **AI auto-edit** | «Замбараагүй яриаг шууд буулгамаар текст болгоно» | ❌ **байхгүй** (дүрмээр цэг таслал тавьдаг) |
| **Контекст мэдрэх** | (1) идэвхтэй апп, (2) курсорын эргэн тойрны текст, (3) юу бичиж байгаа төрөл | ❌ байхгүй (цонхны нэр мэдэгддэг ч ашигладаггүй) |
| **Agent mode** | Текстийг зөвхөн буулгахгүй, үйлдэл хийнэ | ⚠️ Hermes гүүр — аппаас гадна |
| **Tools (beta, 2026-07-18)** | Агент нь гадаад үйлчилгээ рүү холбогдоно | ❌ байхгүй |
| Хувийн толь + **prompt** | Үг солих ба өөрийн заавар | ⚠️ толь байна, prompt байхгүй |
| Түүх + хайлт | Сүүлийн нэмэлт | ✅ байна (бүр 2025 оноос) |
| Хэрэглээний тоо | Вэб самбарт | ✅ байна (аппад) |
| 100 хэл | | ⚠️ 2 хэл зэрэг (mn + нэг нэмэлт) |

**Үнэ:** Үнэгүй — 7 хоногт 2,000 үг. Pro — $17/сар (жилээр) / $20 (сараар),
хязгааргүй + эрэмбэлсэн боловсруулалт. Enterprise — SSO/SAML, тусгайлсан
боловсруулалт, API.

**Нууцлалын зөрчил (анхаарах нь зүйтэй):** «zero data retention», «local storage»
гэж зарладаг ч AI auto-edit болон агент нь **үүлэн дээр** ажилладаг — өөрөөр хэлбэл
текст чинь гадагш явдаг. Monspeech-ийн README энэ талаар илүү шулуухан бичсэн
байгаа нь давуу тал. LLM нэмэх үедээ энэ шулуун байдлаа хадгалах хэрэгтэй.

## 4. Monspeech-ийн давуу тал (алдаж болохгүй зүйлс)

Судалгааны явцад тодорхой болсон нь — Monspeech зарим талаар **төлбөртэй
аппуудаас давуу**:

1. **Хурд.** 0.26 сек (2 сек яриа). Aqua 450 мс гэж сурталчилдаг, Glaido тоо
   хэлдэггүй. Микрофоныг 45 сек нээлттэй барих заль (13 мс) — өрсөлдөгчид энэ
   талаар юу ч ярьдаггүй.
2. **Үнэгүй, бүртгэлгүй, түлхүүргүй.** Glaido/Wispr-ийн үнэгүй давхарга 7 хоногт
   2,000 үг — өдөрт ~285 үг, өөрөөр хэлбэл 2 минутын яриа. Бодит хэрэглээнд
   хүрэхгүй.
3. **Монгол хэл нэгдүгээрт.** Дуут цэг таслал монголоор («цэг», «шинэ мөр»),
   интерфейс монголоор. Өрсөлдөгчид «100 хэл» гэдэг ч монгол хэлний UX байхгүй.
4. **Яг таг буцаах (Ctrl+Alt+Z).** Оруулсан тэмдэгтийн тоог тоолж устгадаг —
   энэ нь өрсөлдөгчдөд ховор.
5. **Засвараас өөрөө суралцах.** Түүхэн дэх мөрийг засахад толинд өөрөө нэмэгддэг.
   Wispr үүнийг «auto-learning dictionary» гэж зардаг.
6. **18 МБ ганц файл, суулгацгүй.**

## 5. Дутагдаж буй зүйлс ба зөвлөмж

### 5.1 ⭐ LLM цэвэрлэгээ — хоёр шатаар (хамгийн чухал)

**Асуудал:** Google түүхий текст буцаадаг. «за тэгээд ааа маргааш уулзъя гэсэн
юм билээ» → яг тэр чигээрээ шивэгдэнэ. Зах зээлийн бүх апп үүнийг цэвэрлэдэг.

**Хурдны айдас:** README-д Ollama-г 0.1 токен/сек байсан тул хассан гэж бичсэн —
энэ нь **локал** LLM-ийн тухай, зөв шийдвэр байсан. Гэвч үүлэн жижиг загвар
(жишээ нь Claude Haiku 4.5) 300–600 мс-д хариулна.

**Шийдэл — хурдаа алдахгүй арга:**

```
товч тавих
  → Google танина (0.26 сек) → түүхий текстийг ШУУД буулгана   ← хурд хэвээр
  → зэрэгцээгээр LLM цэвэрлэнэ (+0.4 сек)
  → өөрчлөлт байвал: backspace(len(түүхий)) + цэвэр текстийг буулгана
```

Хэрэглэгч 0.26 секундэд текстээ хараад, хагас секундийн дараа нь цэгцэрч байгааг
хардаг. Хүлээх зүйл байхгүй.

**Яагаад Monspeech дээр хийхэд амархан вэ:** солих механизм **аль хэдийн бэхлэгдсэн
байна** — `pipeline.py:114` дэх `deliver(text, backspaces)` болон
[history.py](../monspeech/history.py) дэх `take_last()` нь яг «сүүлд бичсэнийг
устгаад оронд нь өөрийг тавих»-ыг хийдэг (Ctrl+Alt+Z үүн дээр ажилладаг).
Шинэ дэд бүтэц бараг хэрэггүй.

**Анхаарах:** энэ нь нууцлалын шинэ асуудал үүсгэнэ (текст LLM рүү явна). Анхны
утгаараа **унтраалттай** байх ба Тохиргоонд ил тод бичих. Wispr-ийн «Privacy
Mode»-той адил.

**Тест:** `tests/test_textproc.py`-ын хэв маягаар — LLM-ийг хуурамчаар (mock)
орлуулж, «цэвэрлэсэн текст ирвэл зөв тоогоор backspace илгээж байна уу» гэдгийг
шалгах.

### 5.2 ⭐ Танигчийг залгуур болгох

**Асуудал:** [recognizer.py](../monspeech/recognizer.py) нь Google-ийн эндпойнтод
шууд бэхлэгдсэн (`HOST`, `PATH`, `DEFAULT_KEY` модулийн түвшинд). Энэ эндпойнт
албан ёсны биш, SLA байхгүй, README-д өөрөө «хааяа хязгаарлалт тохиож болно» гэж
бичсэн. **Нэг өдөр хаагдвал апп бүхэлдээ зогсоно.**

**Шийдэл:** `recognize(pcm, rate, lang) -> (text, confidence)` гэсэн жижигхэн
интерфейс гаргаад, ард нь `GoogleRecognizer`, `ElevenLabsRecognizer`,
`ChimegeRecognizer`, ирээдүйд `LocalRecognizer`. Тохиргоонд «Танигч» гэсэн
сонголт + API түлхүүрийн талбар.

**Хажуугийн ашиг:** нэг ижил дууг хоёр танигч руу зэрэг явуулж WER-ийг нь бодит
өгөгдөл дээрээ хэмжих боломжтой болно.

**Хүчин чармайлт: бага** — `recognize()` нь аль хэдийн цэвэр интерфэйстэй.

### 5.3 ⭐ Аппаар ялгах горим (Mode / профайл)

Superwhisper-ийн Mode, Wispr-ийн tone matching, Glaido-гийн контекст — гурвуулаа
нэг санаа: **хаана бичиж байгаагаас хамаарч өөрөөр аашил.**

Monspeech-д суурь нь бэлэн: [winfocus.py:128](../monspeech/winfocus.py:128) дэх
`window_title()` болон `config.py` дэх `type_mode_apps` жагсаалт нь аппаар ялгах
логикийг аль хэдийн эхлүүлсэн. Үүнийг өргөтгөх:

| Профайлд хадгалах | Жишээ |
|---|---|
| Хэл | Cursor/VS Code → `en-US`, Messenger → `mn-MN` |
| Өнгө аяс (LLM prompt) | Gmail → албан ёсны, Messenger → энгийн |
| Шууд бичих горим | (аль хэдийн байна) |
| Толь | Кодын нэр томьёо зөвхөн IDE-д |

### 5.4 ⭐ Агент горим — Hermes гүүрийг апп руу

`tools/monspeech_hermes_bridge.py` (репод орсон; daily note-ийн зам нь
`MONSPEECH_DAILY_DIR` орчны хувьсагчаас уншина) бол үнэндээ
**Glaido-гийн Agent Mode-ын прототип**: танигдсан текстийг Hermes рүү явуулж,
хариуг clipboard-д тавьдаг, `--trigger` үгээр шүүдэг, Obsidian-ы daily note руу
бичдэг.

Үүнийг тусдаа скрипт биш, аппын **гуравдахь товчлуур** болговол:

- `Win+Alt` → текст буулгана (одоогийнх)
- `Win+Shift` → хоёр дахь хэл (одоогийнх)
- **`Win+Ctrl` → асуулт болгож явуулаад ХАРИУГ нь буулгана** ← шинэ

Ингэснээр «энэ имэйлд хариу бич» гэж хэлэхэд бэлэн хариу курсор дээр орно.
Энэ нь Glaido сард $17-оор зарж байгаа зүйл.

**Санамж:** гүүр нь `history.jsonl`-г уншдаг тул үг бүрийг гадагш явуулах эрсдэл
бий — аппад оруулахдаа **зөвхөн тусгай товчоор дуудагдсан үед** явуулдаг байх.

### 5.5 Дуугаар засварлах (Aqua-гийн загвар)

Одоо: 12 бэхлэгдсэн команд («цэг», «шинэ мөр»…).
Дараагийн шат: «сүүлийн өгүүлбэрийг устга», «үүнийг жагсаалт болго», «англи руу
орчуул» гэх мэт **байгалийн хэлээр**. LLM давхарга (5.1) орсны дараа энэ нь бараг
үнэгүй нэмэлт болно — ялгаа нь зөвхөн «энэ бол шивэх текст үү, эсвэл заавар уу»
гэдгийг ялгах.

### 5.6 Жижиг боловч мэдэгдэхүйц нэмэлтүүд

| Юу | Хэн хийдэг | Тайлбар |
|---|---|---|
| **Хэл автоматаар таних** | Wispr, Glaido | Win+Shift дарахаа мартах шаардлагагүй болно |
| **Дууны бичлэгийг түүхэнд хадгалж дахин сонсох** | Glaido (playback) | Буруу таньсныг шалгахад чухал. Дискний зай эрсдэлтэй — сүүлийн 20-г л барих |
| **Файл хөрвүүлэх** (mp3/mp4 → текст) | Superwhisper | Хурал, ярилцлага. Одоо байгаа танигчаа дахин ашиглана |
| **Чимээгүй/шивнэсэн яриа** | Wispr «whisper mode» | `audio.py`-ийн орчны чимээний босго аль хэдийн дасан зохицдог — тусгай горим болгож ил гаргах |
| **Дууны сануулга** (эхлэх/дуусах чимээ) | Ихэнх нь | Долгион харагдахгүй үед (бүтэн дэлгэц) хэрэгтэй |
| **Өөрийн API түлхүүр** | Whispering, OpenWhispr | Мөнгө авахгүйгээр чанартай хөдөлгүүр өгөх зам |

### 5.7 Хийх шаардлагагүй гэж үзсэн зүйлс

- **Гар утасны апп** — өөр төсөл. Windows дээрх фокусаа алдана.
- **Хамтын ажиллагаа / SSO / багийн эрх** — Enterprise зах зээлийн зүйл.
- **Локал Whisper** — README-д хэмжсэнээр монгол хэлэнд боломжгүй хэвээр.
  Хүчирхэг GPU гарч ирвэл 5.2-ын залгуураар дараа нь нэмэгдэнэ.
- **Вэб хяналтын самбар** — Glaido-д байгаа ч Monspeech-ийн «бүртгэлгүй»
  зарчимтай зөрчилдөнө.

## 6. Монгол хэлний хөдөлгүүрийн сонголтууд — 2026 оны байдал

README-д 2025 онд Chimege/Echo-г үнээр нь хассан байсан. Одоо байдал өөрчлөгдсөн:

| Хөдөлгүүр | Үнэ | Монгол хэлний чанар | Тэмдэглэл |

**Зөвлөмж:** ElevenLabs-ыг **дахин авч үзэх нь зүйтэй**. 24₮/мин гэдэг нь 2025 онд
хассан үеийн тооцооноос эрс өөр. Гэхдээ WER 20.1% нь гайхалтай биш — 5.2-ын
залгуур гарсны дараа **өөрийн дуугаараа A/B хийж** шийдэх нь зөв.

⚠️ **Шалгах шаардлагатай:** ElevenLabs-ийн монгол хэлний хуудас «бодит цагийн
дамжуулалт хараахан байхгүй, удахгүй гарна» гэж бичсэн байхад өөр эх сурвалж
Scribe v2 нь ~150 мс-ийн streaming API-тай гэж бичсэн байна. Хэрэв streaming
байхгүй бол Monspeech-ийн 0.26 секундийн хурдад нийцэхгүй байж магадгүй —
хэрэгжүүлэхээс өмнө өөрөө хэмжих хэрэгтэй.

## 7. Эрсдэл

1. **Google-ийн задгай эндпойнт хаагдах.** Хамгийн том эрсдэл. 5.2 (залгуур) нь
   зөвхөн сайжруулалт биш, **даатгал**. Хамгийн түрүүнд хийх ажил гэж үзэж болно.
2. **Нууцлалын байр суурь.** LLM нэмэх нь Glaido-гийн хийсэн зөрчилд («local
   storage» гэж зараад үүлэн рүү явуулах) орох эрсдэлтэй. Monspeech-ийн README
   одоо шулуухан бичсэн — LLM орсны дараа ч тэр шулуун байдлаа хадгалах, анхны
   утгаараа унтраалттай байлгах.
3. **Нарийн төвөгтэй болох.** Одоо 6,800 мөр, файл бүр тодорхой үүрэгтэй. Горим,
   профайл, залгуур нэмэхэд энэ цэгц алдагдаж болзошгүй. Profile/Mode-ыг
   `config.py` дотор шинэ модуль болгож тусгаарлах нь зүйтэй.
