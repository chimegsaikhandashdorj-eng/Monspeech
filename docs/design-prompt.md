# Дизайны prompt — Monspeech

> Claude-д дизайны ажил өгөхөд энэ файлыг бүтнээр нь хуулж эхлүүлнэ.
> Доор нэг «ерөнхий prompt» ба гурван богино хувилбар байна.

---

## 1. Ерөнхий prompt (үндсэн)

```
Чи Windows дээрх ажлын ширээний аппын дизайнер бөгөөд хэрэгжүүлэгч.

## Апп
Monspeech — Монгол хэлний дуут бичлэгийн (dictation) апп. Хэрэглэгч товч дарж
ярихад ямар ч цонхонд текст шууд бичигдэнэ. Тохиргооны цонх нь зүүн талын
цэстэй, 8 хуудастай:

  Төлөв · Яриа · Бичилт · Товчлуур · Толь · Түүх · Нэмэлт · Аппууд

Хэрэглэгч нь голдуу монгол хэлтэй, техникийн бус хүн. Цонхыг өдөрт нэг л
удаа нээж тохируулаад хаадаг — гоо сайхнаас илүү ОЙЛГОМЖ чухал.

## Технологи ба хатуу хязгаарлалт
- Python 3.11 + **Tkinter** (CSS байхгүй, ttk загвар хязгаартай).
- Дугуй өнцөг, toggle, slider, icon бүгд **Pillow-оор зурсан зураг** —
  `widgets.py`, `icons.py` дотор. Шинэ хэлбэр = шинэ зураг зурах код.
- Өнгө/хэмжээ/фонт бүгд `monspeech/theme.py` дотор ТОКЕН болж төвлөрсөн.
  Виджет дотор хатуу өнгө бичихийг хориглоно.
- Tk-д өнгө нь виджет ҮҮСЭХ агшинд тогтдог: `theme.apply()` дуудахад
  байгаа виджет өөрчлөгдөхгүй, цонхыг бүтнээр дахин барина.
- Харанхуй ба гэрэлтэй хоёр сэдэв ЗААВАЛ хоёулаа ажиллана.
- `tests/test_theme.py` нь сэдэв бүрийн ялгарлыг (contrast) шалгадаг:
  энгийн текст ≥ 4.5:1, том текст ≥ 3:1. Өнгө өөрчилвөл энэ тест давах ёстой.
- Зайн шатлал 4 пикселийн алхамтай (`SPACE_XS…SPACE_2XL`). Шинэ зай нэмэхдээ
  шатлалаас сонгоно, гараар шинэ тоо бичихгүй.
- Цонх 640 px хүртэл нарийсна; 780 px-д зүүн цэс дүрс болж хумигдана.

## Юу хиймээр байна
Цонхны дизайныг мэргэжлийн түвшинд өргөх. Гэхдээ дүрээ бүрэн солих биш —
одоо байгаа токен/виджетийн системийг ХҮНДЭТГЭЖ, дотор нь сайжруул.

## Ажлын дараалал (заавал энэ дарааллаар)
1. **Эхлээд шүүмж, код бичихгүй.** `theme.py`, `widgets.py`, `window.py`-г
   уншаад дизайны 8–12 бодит асуудлыг ол. Асуудал бүрд:
   - хаана байгаа (файл:мөр),
   - яагаад асуудал вэ (хэрэглэгчийн зовлонгоор, «муухай» гэж биш),
   - нөлөө нь хэр (өндөр / дунд / бага),
   - засах зардал (жижиг / дунд / том).
   Дараа нь «эхлээд юуг засах вэ» гэсэн эрэмбэ санал болго.
2. **Миний зөвшөөрлийг хүлээ.** Би алийг нь хийхийг сонгоно.
3. **Дараа нь хэрэгжүүл** — сонгосон зүйлийг бүтнээр, тест ба ruff цэвэр
   байлгаж.

## Дизайны шалгуур (шүүмжлэхдээ эдгээрийг хар)
- **Мэдээллийн шатлал** — хуудас нээхэд нүд хаана эхлэх нь тодорхой юу?
  Хамгийн чухал хяналт хамгийн дээр байна уу?
- **Бүлэглэл** — хоорондоо холбоотой тохиргоо нэг картад цуглаж, ялгаатай нь
  салсан уу? Карт хэт урт болж жагсаалт мэт болоогүй юу?
- **Хэмнэл** — зай, шугам, хүрээ давтагдсан хэв маягтай юу, эсвэл санамсаргүй
  тоонууд орооцолдсон уу?
- **Текст** — Монгол хэл дээрх шошго товч, үйл үгээр эхэлсэн, ойлгомжтой юу?
  Тайлбар нь «юу болох»-ыг хэлж байна уу, эсвэл техникийн нэр давтаж байна уу?
- **Төлөв харуулах** — бичиж байгаа / хүлээж байгаа / алдаа гарсан төлөв нь
  нэг харцаар ялгарч байна уу?
- **Хоосон төлөв** — Түүх, Толь хоосон үед хэрэглэгч дараа нь юу хийхээ
  мэдэх үү?
- **Хүртээмж** — гарын товчоор бүх зүйлд хүрэх үү? Фокус харагдана уу?
  Утга нь зөвхөн өнгөөр илэрхийлэгдээгүй биз?
- **Хариу үйлдэл** — товшсон, хадгалсан, амжилтгүй болсон нь мэдрэгдэж
  байна уу?

## Дүрэм
- Хариултаа монголоор бич. Кодын тайлбар мөн монголоор (файлын хэв маягтай нэг).
- Шинэ өнгө нэмэх бол ХОЁУЛАА (dark, light) сэдэвт нэм, contrast-ыг тооцоод хэл.
- Хийсэн бүр өөрчлөлтөд `.venv\Scripts\python.exe tests\run_all.py` ба
  `.venv\Scripts\python.exe -m ruff check monspeech tests` ажиллуулж, үр дүнг
  нь надад бодитоор харуул.
- «Сайжруулсан» гэж хэлэхийн оронд ЮУ өөрчилснөө, ЯАГААД гэдгээ нэг өгүүлбэрээр
  хэл.
- Хэрэв ямар нэг санаа Tkinter дээр хийх боломжгүй/хэт үнэтэй бол шууд хэл —
  чадахгүй зүйл рүү цаг үрэхгүй.
```

## 2. Богино хувилбар — зөвхөн нэг хуудас

```
Monspeech аппын `monspeech/window.py` дэх «Яриа» хуудсыг (`_page_speech`)
дизайны талаас нь шүүмжилж, сайжруул.

Контекст: Tkinter, өнгө/зай нь `theme.py` токен, виджет нь `widgets.py`
(Card, Toggle, Slider, LevelMeter). Хатуу өнгө бичихгүй. Харанхуй, гэрэлтэй
хоёр сэдэв хоёулаа ажиллах ёстой. `tests/test_theme.py` нь contrast шалгана.

Эхлээд асуудлуудыг жагсаа (код бичихгүй), эрэмбэл, миний сонголтыг хүлээ.
Дараа нь хэрэгжүүлээд тест + ruff-ыг ажиллуул. Монголоор бич.
```

---

## 3. Богино хувилбар — өнгөний систем

```
Monspeech-ийн `monspeech/theme.py` дэх өнгөний палитрыг мэргэжлийн дизайн
системийн нүдээр шүүмжил.

Шалгах зүйл:
- DARK ба LIGHT хоёрын хооронд ойлголт нь тогтмол байна уу (ижил токен ижил
  үүрэг гүйцэтгэж байна уу)?
- Гадаргууны шатлал (BG → PANEL → PANEL2) хангалттай ялгарч байна уу?
- ACCENT, LINK, TOGGLE_ON гурав хоорондоо зөв харьцаж байна уу?
- OK/WARN/DANGER нь зөвхөн өнгөөр биш ялгарах боломжтой юу?
- Дутуу токен байна уу (жишээ нь: idle/disabled, амжилтын дэвсгэр, сануулгын
  дэвсгэр)?

Санал болгосон өнгө бүрийн contrast-ыг тооцоод тоогоор нь харуул
(`tests/test_theme.py` дэх шалгуур: энгийн текст 4.5:1, том текст 3:1).
Эхлээд шүүмж, дараа нь миний зөвшөөрлөөр код. Монголоор бич.
```

## 4. Богино хувилбар — эхлээд HTML дээр загварчлах

> Tkinter дээр шууд туршихаас хурдан: HTML mock хийж, таалагдвал токеныг
> `theme.py` руу буулгана.

```
Monspeech аппын тохиргооны цонхны шинэ дизайны САНААГ HTML/CSS mock болгож
харуул (нэг файл, гадны сан ашиглахгүй).

Одоогийн бүтэц: зүүн талд 208 px цэс (Төлөв, Яриа, Бичилт, Товчлуур, Толь,
Түүх, Нэмэлт, Аппууд), баруун талд гүйдэг хуудас — гарчиг, дэд гарчиг, дараа
нь дугуй өнцөгтэй картууд. Карт дотор мөр бүр: зүүн талд нэр + жижиг тайлбар,
баруун талд хяналт (toggle / slider / товч).

Цонхны хэмжээ 880×620. Харанхуй, гэрэлтэй хоёр хувилбарыг хоёуланг нь үзүүл.

САНАМЖ: эцсийн эх сурвалж нь Tkinter тул дараах зүйлийг ашиглаж БОЛОХГҮЙ —
сүүдэр (box-shadow), бүдгэрүүлэлт (blur), градиент дэвсгэр, шилжилтийн
анимаци, SVG дүрс. Зөвхөн хавтгай өнгө, дугуй өнцөг, хүрээ, зай, фонтын
жингээр л ажилла. Эцэст нь өнгө бүрийг `theme.py`-гийн токен нэрээр
(BG, PANEL, PANEL2, BORDER, TEXT, MUTED, DIM, ACCENT…) жагсааж өг.
```
