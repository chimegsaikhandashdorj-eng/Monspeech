# Monspeech — үнэгүй хэвээр үлдэж, тараагдах апп болох төлөвлөгөө

**Огноо:** 2026-08-13
**Хязгаарлалт:** зардал 0₮ · GPU байхгүй → локал LLM боломжгүй · зорилго: Glaido шиг бодит desktop апп

---

## 0. Хоёр хатуу үнэн

### 0.1 Локал загвар яг одоо хаалттай — зөв шийдвэр

Хэмжсэн: **Intel UHD 770 (тусдаа GPU байхгүй), RAM 7.7 ГБ, i7-12700**.

RAM 7.7 ГБ гэдэг нь GPU байхгүйгээс ч илүү хатуу хязгаар. Whisper `medium` (≈5 ГБ)
болон 7B LLM (≈5–8 ГБ) хоёулаа систем дээр багтахгүй. README-д хэмжсэн «3 сек дууг
47 сек» гэдэг тоо хэвээрээ.

**Гэхдээ:** энэ бол *чиний машины* хязгаар, *аппын* хязгаар биш. Тараах үед
хэрэглэгчдийн дунд RTX-тэй машин байх болно. Тиймээс локал сонголтыг **үгүйсгэхгүй,
харин залгуурын ард нээлттэй үлдээх** — өөрөө ашиглахгүй ч бүтэц нь бэлэн байна.

### 0.2 ⚠️ Тараахад хамгийн түрүүнд хагарах зүйл: хуваалцсан Google түлхүүр

Энэ бол хамгийн чухал хэсэг тул тодруулж бичье.

`recognizer.py:22` дэх `DEFAULT_KEY` бол Chromium-ийн задгай түлхүүр. **Бүх
хэрэглэгч нэг л түлхүүр дээр сууна.** Одоо 1 хэрэглэгчтэй тул ажиллаж байна.
50–100 хэрэглэгчид тарааж, хүн бүр өдөрт хэдэн зуун удаа дарвал:

- 429 (хэт олон хүсэлт) бүх хэрэглэгчид **зэрэг** цохино
- 403 гарвал апп бүхэлдээ, бүх хэрэглэгчийн машин дээр зогсоно
- Чи юу ч хийж чадахгүй — түлхүүр чинийх биш

Өөрөөр хэлбэл **одоогийн бүтэц нь ганц хэрэглэгчид ажиллана, тараахад ажиллахгүй.**
Энэ нь «дараа засна» гэж болох зүйл биш, харин тараахаас өмнө шийдэх ёстой
архитектурын асуудал.

**Үнэгүй шийдэл — BYOK (хэрэглэгч өөрийн түлхүүрээ авчрах):**

| Хэн | Юу төлөх | Юу авах |
|---|---|---|
| Чи (хөгжүүлэгч) | **0₮ үүрд** — сервер, дамжуулагч, дундын түлхүүр байхгүй | Хязгааргүй хэрэглэгч |
| Хэрэглэгч | 0₮ — үнэгүй tier-ийн түлхүүрээ өөрөө авна | Өөрийн квот, өөрийн нууцлал |

Гурван шатлал болгоно:

1. **Түлхүүргүй (анхны утга)** — Google Web Speech, одоогийнх. Суулгамагц ажиллана.
   «Хааяа тасалдаж болно» гэж шулуун бичнэ.
2. **Өөрийн түлхүүр (сонголт)** — Тохиргоонд наах талбар. Тогтвортой, чанар өндөр.
3. **Локал (ирээдүй)** — хүчирхэг машинтай хүнд.

Whispering, OpenWhispr зэрэг нээлттэй эхийн аппууд яг ингэж ажилладаг — тэднийг
хэн ч санхүүжүүлдэггүй, гэсэн ч ажилласаар байгаа.

## 1. Давхарга 0 — түлхүүргүй, машин болгонд, өнөөдөр

Эдгээр нь **API, түлхүүр, интернэт нэмэлт шаардахгүй**, бүх хэрэглэгчид шууд
ажиллана. Тиймээс хамгийн түрүүнд.

### 1.1 Google-ийн буцаасан 3 хувилбарыг ашиглах ⭐ ✅ ХИЙГДСЭН (2026-08-13)

**Одоо юу болж байна:** `recognizer.py:89` дээр `maxAlternatives: 3` гэж
**гуравхан хувилбар гуйж авчихаад**, `_parse()` (мөр 165–187) нь эхний хоосон
биш хувилбарыг буцааж **үлдсэн хоёрыг нь хаядаг**.

Өөрөөр хэлбэл чанар сайжруулах өгөгдөл аль хэдийн хариунд ирчихсэн, ашиглагдалгүй
хаягдаж байна. Нэмэлт хүсэлт, нэмэлт саатал, нэмэлт төлбөр **тэг**.

**Юу хийх:** гурван хувилбарыг оноогоор эрэмбэлэх —
- Хэрэглэгчийн «Үг солих» толь дахь **зөв** үгийг агуулсан хувилбар давуу
- Дуут товчлолын түлхүүр үг агуулсан нь давуу
- Түүхэнд өмнө нь батлагдсан үг агуулсан нь давуу
- Тэнцвэл Google-ийн эрэмбэ хэвээр

Хэрэглэгч «клауд → Claude» гэж толиндоо нэмсэн бол хувилбар #2 нь «Claude» гэж
байвал шууд түүнийг сонгоно. Толь одоо *дараа нь* үг сольдог; энэ нь *эхнээс нь*
зөвийг сонгоно.

**Хэрэгжсэн байдал:**
- `Recognizer.recognize()` ба `_parse()` нь `(хувилбарууд, итгэлцэл)` буцаадаг болов.
  Итгэлцлийг үйлчилгээ зөвхөн эхний хувилбарт өгдөг тул түүнийг хэлсэн зүйлийн
  ерөнхий итгэлцэл гэж үзнэ — аль хувилбарыг сонгосон ч `min_confidence` шүүлт
  хэвээр ажиллана.
- `textproc.choose_alternative()` нь толь + дуут товчлол + **түүхээр** оноолж
  сонгоно. Оноо: дуут товчлол 3, толийн зөв тал 3, толийн буруу тал 2 (ямар ч
  байсан засагдана), түүхэнд батлагдсан үг 1. Тэнцвэл үйлчилгээний эрэмбэ хэвээр.
- Түүхийн талыг `Formatter` эзэмшинэ: `remember()` нь батлагдсан текстийг санаж
  (сүүлийн 40), `choose()` нь толь/товчлол/түүх гурвыг нийлүүлж сонгоно. Ингэснээр
  дамжлага нь толь, товчлолыг тус тусад нь мэдэх шаардлагагүй. Апп эхлэхдээ
  дискэн дэх түүхээр үрээнэ.
- Дуут командыг оноололд **оруулаагүй** — «цэг» гэж сонсогдсон бүхнийг дэвшүүлбэл
  жинхэнэ үгийг цэг болгож гээх эрсдэлтэй.
- Лог руу текст бичихгүй, зөвхөн хэд дэх хувилбарыг сонгосон дугаарыг.
- Тест: `test_textproc.py`, `test_stt_google.py` (энэ файл өмнө нь
  `test_recognizer.py` нэртэй байсан), `test_pipeline.py`.

**Синерги:** «Засварыг сурна» онцлог толийг өөрөө тэжээдэг тул хэрэглэгч засвар
хийх тусам эхний сонголт нь сайжирна.

### 1.2 Монгол хэлний дүрмээр цэвэрлэгээ ⭐ ✅ ХИЙГДСЭН (2026-08-13)

LLM-гүйгээр «AI auto-edit»-ийн мэдэгдэхүйц хэсгийг дүрмээр авч болно:

| Юу | Жишээ |
|---|---|
| Чигчлүүр үг хаях | «за ааа маргааш уулзъя» → «Маргааш уулзъя» |
| Давхардсан үг хураах | «би би би» → «би» |
| Өөрийгөө засах | «5 цагт... **үгүй ээ** 6 цагт» → «6 цагт» |
| «тэгээд тэгээд», «юу гэх вэ», «тийм ээ» | хаях |
| Цэгийн өмнөх зай, давхар зай | засах |

Энэ нь LLM-тэй тэнцэхгүй, гэхдээ **хэрэглэгчийн нүдэнд харагдах ялгааны 50–60%
нь** энэ. Хугацаа 0 мс, түлхүүр хэрэггүй, офлайн ажиллана.

Чигчлүүр үгсийн жагсаалтыг `VOICE_COMMANDS`-той адилаар `textproc.py` дотор
тавьж, Тохиргооноос унтраадаг болгох (зарим хүн үгчлэн бичүүлэхийг хүсдэг).

**Хэрэгжсэн байдал:** `textproc.clean_speech()` — дөрвөн алхам: утгагүй чимээ →
эхний чигчлүүр → өөрийгөө засах → давталт хураах. Тохиргооны түлхүүр
`clean_speech` (анхнаасаа асаалттай), «Бичилт» хуудсанд чагт, урьдчилан харах
жишээнд тусна.

**Хамгаалалтууд** (эргэлзвэл хөндөхгүй зарчим):
- «ээ», «уу», «үү» нь чимээний загварт **байхгүй** — эдгээр нь монгол хэлний
  жинхэнэ бөөм («тийм ээ», «байна уу», «мөн үү»)
- «аа», «өө» нь **уртаараа** ялгагдана: яг хоёр үсэгтэй нь үгийн араас байвал
  эгшиг зохицлын бөөм («явъя аа», «өгье өө») тул үлдэнэ, эхэнд байвал чимээ;
  гурав ба түүнээс дээш («ааа») бол хаана ч сунгасан чимээ
- «за», «тэгээд» зөвхөн **эхнээс** хасагдана — дунд байхад утгатай
- Засварын тэмдэг нь зөвхөн **хоёр үгтэй** хэллэг («үгүй ээ», «биш ээ») — дан
  «үгүй», «биш» бол өдөр тутмын үг
- Засвар олдвол сүүлийн цэг таслал хүртэл л ухарна — өмнөх бүтэн өгүүлбэр үлдэнэ.
  Хил нь **хоёр хэлбэртэй**: хэлсэн цэг таслал («цэг» гэж дуудсан) ба танигчаас
  бэлнээр ирсэн бичигдсэн цэг таслал. Сүүлийнх нь OpenAI танигч, `en-US` хариунд
  ирдэг тул хоёуланг нь `_is_boundary()` хардаг
- Иш татсан үгийг хамгаална (`QUOTE_MARKERS`): «за гэж хэлээд явлаа» хэвээрээ.
  Энэ нь бодит өгүүлбэрүүд дээр туршиж байж илэрсэн цорын ганц алдаа байв
- «маш маш сайн» гэх чангатгах давталтыг хураахгүй (`EMPHASIS` жагсаалт)
- Давтагдсанаас сүүлчийнхийг үлдээнэ — цэг таслал сүүлийн үгэнд наалддаг
- Зөвхөн чигчлүүр сонсогдвол текст оруулахгүй, «Зөвхөн чигчлүүр үг сонсогдлоо»
  гэж мэдэгдэнэ (чимээгүй бүтэлгүйтэхгүй). Итгэлцлийн шүүлт **үүнээс өмнө**
  явна — эс бөгөөс итгэлцэл багатай чимээ буруу шалтгаан харуулна

**Тест:** `test_textproc.py` (үүнд «хасаж болохгүй» тохиолдлууд),
`test_pipeline.py`, `test_window.py`.

### 1.3 Аппаар ялгах профайл

`winfocus.window_title()` болон `config.py` дахь `type_mode_apps` нь суурийг нь
тавьчихсан. Аппад: хэл + шууд бичих + цэвэрлэгээний хатуулаг.

Cursor/VS Code → `en-US`, Messenger → `mn-MN`. Win+Shift дарахаа мартах шаардлагагүй.

### 1.4 Хэлийг сэжиглэх (нэмэлт хүсэлтгүйгээр)

`mn-MN`-ээр таньсан үр дүнгийн итгэлцэл босгоос доогуур **бөгөөд** текст нь
кирилл биш байвал `en-US`-ээр нэг удаа дахин оролдох. Тодорхойгүй тохиолдолд л
хоёр дахь хүсэлт явна — дунджаар зардал бараг нэмэгдэхгүй.

### 1.5 Түүхэнд дууг хадгалж дахин сонсох

16 кГц PCM = 32 КБ/сек. Сүүлийн 20 бичлэг × 5 сек ≈ 3 МБ. «Яагаад ингэж таньсан
юм бэ» гэдгийг шалгах цорын ганц арга. Дискний хязгаартай, Тохиргооноос унтраадаг.

### 1.6 Дуут сануулга

Эхлэх/дуусах богино дуу. Бүтэн дэлгэцтэй тоглоом, видео дээр долгион харагдахгүй
үед цорын ганц санал хариу.

## 2. Давхарга 1 — үнэгүй боловч түлхүүр шаардана (BYOK)

### 2.1 Танигчийн залгуур ⭐⭐ ✅ ХИЙГДСЭН (2026-08-13)

```python
class SpeechProvider(Protocol):
    def recognize(self, pcm: bytes, rate: int, lang: str) -> list[tuple[str, float]]: ...
```

Ард нь: `GoogleWebSpeech` (одоогийнх, түлхүүргүй) · `UserKeyProvider` (хэрэглэгчийн
өөрийн түлхүүр) · ирээдүйд `LocalProvider`.

**Хэрэгжсэн байдал:**

| Файл | Үүрэг |
|---|---|
| `recognizer.py` | `Provider` суурь, `PROVIDERS` бүртгэл, `create(cfg)`, `titles()`, ба хүсэлт явуулах `request()` |
| `stt_google.py` | Одоогийнх нь бүхэлдээ нүүсэн — зан төлөв өөрчлөгдөөгүй |
| `stt_openai.py` | `POST …/v1/audio/transcriptions` бичиглэлтэй дурын үйлчилгээ |

- Тохиргоо: `stt_provider` (`google`/`openai`), `stt_url`, `stt_model`, `stt_key`.
  **Анхны утга нь одоогийн зан төлөв яг хэвээр** — хуучин хэрэглэгч юу ч
  анзаарахгүй.
- Цонх: «Яриа» хуудсанд «Танигч» цэс. Нэмэлт талбарууд зөвхөн өөрийн үйлчилгээ
  сонгоход л гарна.
- Танихгүй нэр (гараар `config.json` засах, хуучин хувилбар) бол чимээгүй Google
  руу буцна — апп ажиллахаа болихоос дээр.
- Импорт нь үүсгэгч функц дотор: танигчид `recognizer`-оос `Provider` авдаг тул
  дээд түвшинд импортловол тойрог үүснэ. `monspeech.spec`-д hiddenimports нэмэв.
- **Шинэ танигч нэмэхэд зөвхөн `PROVIDERS`-д мөр нэмнэ.** Гарчиг, үүсгэгч, анхны
  утга руу буцах бүгд тэндээс уншина — өмнө нь `create()`, `titles()`, классын
  талбар гэсэн гурван газарт давхардаж бичигддэг байв.
- **Сүлжээний давхарга нэг дор:** дахин оролдох давталт, хүлээлт, статусыг
  хэрэглэгчийн хэлээр алдаа болгох нь `recognizer.request()`-д төвлөрөв. Танигч
  бүр зөвхөн `send(оролдлого) -> (статус, бие)` хаалт ба өөрийн онцгой
  статусуудын `ERRORS` толийг өгнө. Ингэснээр шинэ танигч автоматаар ижил
  сүлжээний зан төлөвтэй болно.
- Тест: `test_recognizer.py` (залгуур), `test_stt_openai.py` (WAV, multipart,
  хариу, статус, дахин оролдлого), `test_stt_google.py` (энэ нь өмнөх
  `test_recognizer.py` нэрээ сольсон нь), `test_window.py`.

**Хоёр ялгаа (README-д баримтжуулсан):** OpenAI бичиглэл нь олон хувилбар
буцаадаггүй тул 1.1-ийн толиор сонгох ажиллахгүй; итгэлцэл өгдөггүй тул
«Итгэлцлийн босго» шүүлт хийхгүй (1.0 буцаана).

**Замд таарсан алдаа:** «Яриа» хуудсанд урт тайлбартай мөр нэмэхэд цонх
хэмжээгээ тогтоож чадахгүй **төгсгөлгүй эргэлдэж гацсан**. Гүйлгэгч гарч ирэх →
талбар нарийсах → урт тайлбар нэмэлт мөрөнд шилжих → агуулга уртсах → гүйлгэгч
хэрэгтэй хэвээр… гэсэн гогцоо. Богино тайлбар (аппын бусад мөрүүдийн адил
хэв маяг) нь үүнийг тойрсон. **Энэ нь далд алдаа хэвээр** — ирээдүйд урт
тайлбар нэмэхэд дахин гарч болзошгүй тул `ScrollFrame`-ийн гүйлгэгчийг
`place`-ээр давхарлах нь жинхэнэ засвар болно.

### 2.2 Текст цэвэрлэх LLM — зөвхөн түлхүүртэй хэрэглэгчид

Давхарга 0-ийн дүрмүүд хүрэлцэхгүй хүн өөрийн үнэгүй tier-ийн түлхүүрээ хийвэл
жинхэнэ AI цэвэрлэгээ авна. Хоёр шаттай буулгалт (түүхийг нь шууд, дараа нь солих)
хурдыг хамгаална — `deliver(text, backspaces)` механизм бэлэн.

**Анхны утгаараа унтраалттай.** Текст гадагш явах бүрд хэрэглэгч мэдэж байх ёстой.

> ⚠️ **Шалгах:** ямар үйлчилгээ 2026 оны 8 сард картгүйгээр үнэгүй tier өгч байгаа,
> хязгаар нь хэд болохыг хэрэгжүүлэхийн өмнө нягтлах. Судалгаа хийх үед энэ хэсгийг
> бүрэн шалгаж амжаагүй.

### ⚠️ Шинэчлэл шалгах нь Release нийтлэх хүртэл юу ч олохгүй

Бүтээсэн `.exe`-г ажиллуулж шалгахад лог руу `шинэчлэл шалгах: 404 хариу` гэж
бичив — репод хараахан ямар ч Release нийтлээгүй байна. Код нь зөв ажиллаж
байгаагийн шинж (алдаа шидэлгүй, чимээгүй өнгөрсөн) боловч онцлог нь ажиллахын
тулд GitHub дээр `v0.2.0` гэсэн шошготой Release үүсгэж, `Monspeech.exe`-г
хавсаргах шаардлагатай.

### 3.1 SmartScreen — шулуун үнэн

Гарын үсэг зурах гэрчилгээ **үнэгүй байхгүй**. Azure Trusted Signing ≈ $10/сар,
уламжлалт EV гэрчилгээ жилд $200–400.

Үнэгүй бууруулах аргууд:
- Үргэлж **нэг ижил GitHub Releases**-ээс тараах — SmartScreen нэр хүнд хуримтлуулдаг
- README-д «More info → Run anyway» гэдгийг эхний хуудсанд тодоор бичих (одоо байгаа ✅)
- `winget` жагсаалтад оруулах — үнэгүй, суулгах итгэл нэмнэ
- Тодорхой хугацаанд татагдсаны дараа анхааруулга өөрөө арилдаг

### 3.2 Өөр үйлдлийн систем рүү гарах

Одоо Windows-д бэхлэгдсэн хэсгүүд:

| Файл | Юу нь Windows-ийнх |
|---|---|
| [injector.py](../monspeech/injector.py) | Виртуал товчийн код `0x56`, UIPI |
| [winfocus.py](../monspeech/winfocus.py) | Win32 цонхны API бүхэлдээ |
| [autostart.py](../monspeech/autostart.py) | Бүртгэлийн `Run` түлхүүр |
| [overlay.py](../monspeech/overlay.py) | `WS_EX_NOACTIVATE`, `MonitorFromPoint` |
| [hotkeys.py](../monspeech/hotkeys.py) | pynput — үнэндээ кросс-платформ ✅ |

**5 файл.** Бусад 15 нь цэвэр Python. Энэ бол сайн байдал — эдгээрийг
`platform/windows.py`, `platform/macos.py` болгон тусгаарлавал macOS руу гарах зам
нээгдэнэ. Гэхдээ **энэ нь одоо биш** — эхлээд Windows дээр бүрэн бэлэн апп болго.

### 3.3 Давуу тал: Glaido Electron биш гэдгээрээ сайрхдаг — Monspeech түүнээс ч жижиг

Monspeech = **18 МБ ганц файл, суулгацгүй**. Electron апп 150–250 МБ. Энэ бол
сурталчилгаанд шууд ашиглах тоо.
