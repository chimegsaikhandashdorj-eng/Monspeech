# Монгол–англи benchmark

Танилтын сайжруулалт бүр **хэмжигдэх** ёстой. Энэ хавтас нь тэр хэмжүүр.

## Хамгийн хурдан зам: аппаараа өөрөө цуглуулах

«Яриа → **Хэцүү жишээ хадгалах**»-ыг асаагаад ердийнхөөрөө хэдэн өдөр ажилла.
Апп нь буруу таньсан дуунуудыг өөрөө хураана — ялангуяа чи түүхэн дээр засах
эсвэл **Ctrl+Alt+Space** дарж хувилбар сэлгэх бүрд «дуу нь энэ, зөв нь энэ»
гэсэн бүрэн хос үүснэ. Дараа нь:

```powershell
.venv\Scripts\python.exe tools\make_manifest.py --all
```

Дууг `benchmarks\audio\` руу хуулж, `benchmarks\manifest.jsonl` үүсгэнэ.
Зөв хариу нь мэдэгдэхгүй мөрүүд (огт танигдаагүй, итгэлцэл багатай) `#`-ээр
эхэлж бичигдэнэ — сонсоод `text`-ийг нь бөглөж, `#`-ийг нь авбал ажиллана.
Тэдгээр нь хамгийн хэцүү жишээнүүд тул бөглөх нь үнэ цэнэтэй.

## Гараар бэлдэх

`manifest.example.jsonl`-ийг `manifest.jsonl` болгон хуулж, `audio` хавтсанд
өөрийн 16 кГц, mono, 16-bit PCM WAV бичлэгүүдийг байрлуулна. Аудио болон бодит
manifest-ийг хувийн мэдээлэл агуулж болох тул git-д оруулахгүй.

Ангилал бүрээс дор хаяж 25 жишээ санал болгоно:

- цэвэр монгол;
- цэвэр англи;
- монгол өгүүлбэр дэх англи нэр/техникийн үг;
- нэг өгүүлбэрт хоёр хэл;
- чимээтэй, хурдан, аяархан яриа.

## Ажиллуулах

```powershell
.venv\Scripts\python.exe tools\benchmark_language.py benchmarks\manifest.jsonl
```

```powershell
.venv\Scripts\python.exe tools\benchmark_language.py benchmarks\manifest.jsonl --accuracy
```

Эхний тушаал нь тэнцвэртэй cascade, хоёр дахь нь хоёр хэлийг зэрэг таних
нарийвчлалын горим. Хэл зөв сонгосон хувь, WER, CER, p50/p95 latency-г гаргана.

## Хувилбар сонгогчийг хэмжих

Анхдагчаар benchmark нь танигчийн **эхний** хувилбарыг хэмждэг — толь, хэлний
загвар, түүх гурав огт оролцохгүй. Сонгогчийн үнэ цэнийг харахын тулд хоёр
удаа ажиллуулж WER-ийг харьцуулна:

```powershell
.venv\Scripts\python.exe tools\benchmark_language.py benchmarks\manifest.jsonl --report benchmarks\base.json
```

```powershell
.venv\Scripts\python.exe tools\benchmark_language.py benchmarks\manifest.jsonl --choose --report benchmarks\chosen.json
```

`--choose` нь аппынхтай ЯГ ижил сонгогч бэлдэнэ: толь, товчлол, нэрс
тохиргооноос, хэлний загвар нь `history.jsonl`-оос. Загвар хангалттай
сураагүй бол эхлэхдээ мэдэгдэнэ.

`--report` нь мөр тус бүрийн хүлээсэн/гарсан текст, WER, CER, хэл, хугацааг
JSON болгож бичнэ — хоёр ажиллалтыг харьцуулж, ЯМАР мөр өөрчлөгдсөнийг
олоход хэрэгтэй.
