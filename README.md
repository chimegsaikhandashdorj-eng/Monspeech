# Monspeech

Ярианы яриаг текст болгож, **курсор байгаа газарт шууд шивдэг** Windows desktop апп.

Дурын цонхон дээрээ (Notepad, Word, Excel, хөтөч, чат…) **Windows + Alt-ыг дарж барин ярь —
товчоо тавимагц текст тэр дор нь орно.** Аппын цонх нээх, хөтөч ажиллуулах шаардлагагүй.

Микрофоныг шууд уншиж, **Google Web Speech** рүү илгээнэ — бүртгэл, API key, төлбөр хэрэггүй.

> **Нууцлал:** таних ажил үүлэн дээр хийгддэг тул бичсэн дуу тань Google-ийн сервер рүү
> илгээгддэг. Нууц мэдээлэл уншуулахаас өмнө үүнийг анхаарна уу. Аппын лог файлд
> таньсан текст бүтнээрээ бичигддэггүй (зөвхөн урт, итгэлцэл, хугацаа), харин
> түүхийн файлд (`%AppData%\Monspeech\history.jsonl`) бүтнээрээ хадгалагдана —
> цонхны **Түүх → Цэвэрлэх** товчоор устгана.

## Хурд

Товч суллагдснаас текст гартал (хэмжсэн утга, урьдчилан нээсэн холболттой):

| Ярианы урт | Хугацаа |
|---|---|
| 2 секунд | **~0.26 сек** |
| 4 секунд | ~0.5–0.6 сек |

Товч дармагц TLS холболтыг урьдчилан нээдэг тул суллах үед зөвхөн дуу л дамжина.

**Товч дарснаас бичиж эхлэх хүртэл:**

| | Хугацаа |
|---|---|
| Микрофон хаалттай байсан (эхний удаа) | ~800 мс |
| Микрофон бэлэн байсан (дараагийнх) | **~13 мс** |

Микрофон нээхэд эхний дуу ирэх хүртэл ~0.8 секунд болдог (ялангуяа Bluetooth чихэвч)
бөгөөд тэр хугацаанд яриа бүрэн алдагддаг. Иймд бичлэг зогссоны дараа микрофоныг
45 секунд бэлэн байдалд барьдаг — дараалсан бичилтүүд шууд эхэлнэ. Тэр хугацаанд
Windows-ийн микрофоны заалт асаалттай хэвээр байх тул Тохиргооноос багасгах, эсвэл
"Болих" гэж сонгож огт унтраах боломжтой.

## Онцлог

- ⌨️ **Win + Alt дарж барих** — Монгол + English-ийг автоматаар ялгана
- 🌐 **Win + Shift** — хоёр дахь хэлийг зориуд албадан сонгох нөөц товч
- ↩️ **Ctrl + Alt + Z** — сүүлд оруулсан текстийг яг таг устгах. "Буцаа" гэж
  дуугаар ч болно ("хоёр удаа буцаа" гэвэл хоёуланг нь)
- 🗣 **Дуут үйлдэл** — "давт", "хуулж ав", "зогс". Өөрийн хэллэгээ **Толь →
  Дуут үйлдэл** дээрээс нэмнэ
- 🔀 **Ctrl + Alt + Space** — буруу таньсан үгийг дахин ярилгүйгээр танигчийн
  дараагийн хувилбар руу сэлгэнэ (сонгосон хувилбар толинд өөрөө сурагдана)
- 🎛 **Win + Ctrl дарж барих** — команд горим: хэлсэн зүйл текст болж орохгүй,
  зөвхөн үйлдэл гүйцэтгэнэ
- ⏪ **Товчны өмнөх дуу** — товч дарж амжаагүй эхэлсэн үг тасрахгүй: микрофон
  бэлэн байх зуурын сүүлийн 0.6 секундыг бичлэгийн эхэнд залгана
- 🛡 **Буруу цонхонд бичихгүй** — зорилтот цонх идэвхжихгүй бол текстийг өөр
  цонхонд шидэхийн оронд clipboard-д хийж мэдэгдэнэ
- 🎯 **Толиор дохио өгөх** — нэрс, толио танигчид урьдчилан хэлж, «Чимэгсайхан»
  гэдгийг ЭХНЭЭСЭЭ зөв гаргана (OpenAI-нийцтэй танигчид)
- 🧰 **Дуут засвар** — «сүүлийн гурван үгийг устга», «том үсэг болго», «зайг ав»,
  команд горимд «оронд нь …» гэж сүүлийн үгээ солино
- 📄 **Файлаас хөрвүүлэх** — хурлын бичлэг, лекц, дуут тэмдэглэлийг текст болгож,
  эх файлын хажууд `.txt` болгон хадгална
- 🔊 **Системийн дуу** — микрофоны оронд компьютерийн тоглуулж буй дууг бичнэ
  (онлайн хурал, видео). Микрофоны жагсаалтаас «Чанга яригч …»-ийг сонгоно
- 🌬 **Чимээ дарах** — сэнс, кондиционерын гүнгэнээ, завсрын шуугианыг илгээхийн
  өмнө сулруулна (офлайн, ~6 мс)
- 🎚 **Ярианы илрүүлэгч** — өгүүлбэрийн хилийг дууны түвшингээр биш, ярианы
  шинжээр тогтооно: аяархан хэлсэн сүүлийн үе тайрагдахгүй, товчлуурын товшилт
  сегментийг нээлттэй үлдээхгүй (офлайн, уншилт тутамд 0.008 мс)
- 🧠 **Өөрийн ярианаас сурна** — «хурал дээрээ» гэж өмнө нь хэлсэн бол хувилбар
  сонгохдоо түүнийг мэднэ. Түүхээс үгийн хос тоолдог, диск дээр юу ч нэмдэггүй
  локал загвар (LLM биш, 0.05 мс)
- 🔬 **Хэцүү жишээ хадгалах** — буруу таньсан дууг зөв хариутай нь үлдээж,
  сайжруулалтыг ХЭМЖИХ benchmark сан болгоно (анхнаасаа унтраалттай)
- 👆 **Хоёр дарж асаах** — Ctrl-ыг хоёр хурдан дарж бичлэг эхлүүлнэ (сонголттой)
- 💵 **Хэрэглээний тоолуур** — өөрийн танигч ашиглаж байвал өнөөдөр/энэ сарын
  минут ба ойролцоо зардал
- 🔁 **F9** — урт бичихэд: нэг дарж асаагаад, дахин дарж унтраана (чимээгүй завсраар нь
  өгүүлбэр болгон таслаж, яриа дундуур текст оруулна)
- 🔤 **Дуут цэг таслал**: "цэг", "таслал", "асуултын тэмдэг", "шинэ мөр"
- 🧽 **Чигчлүүр цэвэрлэх** — «ааа», эхэнд хэлсэн «за», давхардсан үг, «үгүй ээ»
  гэж өөрийгөө зассаныг өөрөө хасна. Үүлэн ч, LLM ч ашиглахгүй — дүрмээр, 0 мс
- 📝 **Жинхэнэ үгчлэн горим** — цэвэрлэгээ, толь, тоо, цэг таслал, том үсэг,
  товчлол болон дуут үйлдлийг бүгдийг алгасаж provider-ийн эхний transcript-ийг буулгана
- 🅰 Өгүүлбэрийн эхний үсгийг автоматаар том болгоно — **анхдагчаар унтраалттай**
  (таньсан чигээр нь жижгээр орно; хүсвэл **Бичилт → Том үсгээр эхлүүлэх**)
- 🔢 **Тоог цифрээр** — «хорин гурван цагт» гэж хэлэхэд «23 цагт» гэж бичнэ.
  Танигч монголоор тоог үгээр буцаадаг; энэ нь дүрмээр хөрвүүлнэ (0 мс, офлайн)
- 🧑 **Нэрсийн толь** — хүний нэрийг **ойролцоогоор** таьина: «Чимэгсайхан» гэж нэг
  нэмэхэд «чимэг сайхан», «чимэгсайхны», «чимэгсайхантай» бүгд баригдана
- 📖 **Үг солих толь** — байнга буруу танигддаг үгээ өөрөө засна. Толь нь зөвхөн
  дараа нь солиод зогсохгүй, таних үйлчилгээний буцаасан хувилбаруудаас **эхнээс нь
  зөвийг сонгоно** (дэлгэрэнгүйг «Техникийн тэмдэглэл»-ийн 11-ээс)
- 🌊 **Курсорын доорх капсул** — сонсож эхэлмэгц гарч ирж, логоны градиенттай 9 багана
  микрофоны түвшний дагуу хөдөлнө; таних үедээ жигд давалгаа болж, дараа нь үр дүнг
  (ногоон цэг) эсвэл анхааруулгыг (улаан цэг) харуулаад алга болно. Чимээгүй, фокус
  булаахгүй, дамжин товшигдоно
- 🎚 Микрофон сонгох, орчны чимээнд дасан зохицох босго
- 🧹 Илгээхийн өмнө дууг цэгцэлнэ: чимээгүйг тайрч, түвшинг жигдрүүлнэ — сул
  бичлэгийн танилт мэдэгдэхүйц сайжирна
- 🛡 Итгэлцэл багатай үр дүнг оруулахгүй (буруу текст шивэгдэхээс сэргийлнэ)
- 🕘 **Түүх** — дискэнд хадгалагдана, хайлттай, давхар товшвол дахин буулгана
- 🧠 **Засварыг сурна** — түүхэн дэх буруу таньсан мөрийг засахад ялгаатай үгсийг
  толиндоо өөрөө нэмнэ (гараар бөглөх шаардлагагүй)
- ⚡ **Дуут товчлол** — "миний хаяг" гэж хэлэхэд бүтэн хаяг тэлж орно
- 📊 **Хэрэглээний тоо** — өнөөдрийн үг, нийт үг, дундаж хугацаа, хэмнэсэн минут

## Хэрхэн ажилладаг вэ

```
[Микрофон] → PyAudio (16 кГц PCM) → чимээгүйгээр таслах
          → Google Web Speech (HTTPS, шууд) → цэгцлэх → Ctrl+V → курсор
```

Google Web Speech-ийн Chromium ашигладаг эндпойнт рүү түүхий PCM дуу шууд илгээдэг тул
хөтөч, бүртгэл, түлхүүр шаардахгүй. (Энэ нь албан ёсоор гуравдагч талд нээсэн API биш —
хувийн хэрэглээнд хэвийн, гэхдээ SLA байхгүй, хааяа хязгаарлалт тохиож болно.)

### Монгол–англи хэлийг автоматаар таних

**Яриа → Хэл автоматаар таних** анхнаасаа асаалттай. Үндсэн товчоор ярьсан
аудиог монгол, англи хоёрын аль болохыг бичиг, үгийн сан, provider-ийн бодит
итгэлцэл, тухайн цонхны профайл, өмнөх батлагдсан хэлээр сонгоно. Итгэлцэл өндөр
байсан ч латин текст монгол хүсэлтээс (эсвэл кирилл текст англи хүсэлтээс)
гарвал нөгөө хэлээр заавал шалгана.

**Хамгийн зөв таних**-ыг асаавал хоёр хэлний хүсэлтийг зэрэг явуулна. Танилт
илүү найдвартай боловч Google хүсэлтийн тоо хоёр дахин нэмэгдэнэ. Унтраалттай
үед эхний үр дүн зөрүүтэй/эргэлзээтэй байхад л хоёр дахь хүсэлт явдаг.

OpenAI-compatible multilingual model сонгосон үед Auto горим `language`
параметрийг албадахгүй; үйлчилгээ өөрөө хэлээ илрүүлнэ. `language` эсвэл
confidence хариунд ирвэл түүхийн metadata-д хадгална, байхгүй бол хиймэл `1.0`
гэж үзэхгүй.

Нэг өгүүлбэрт хоёр хэл орвол native code-switch дэмждэг model-ийн үр дүнг
шууд ашиглана. Google-ийн хоёр transcript ижил хэмнэлтэй үед хүчтэй монгол,
англи токенуудыг болгоомжтой нэгтгэнэ; эргэлзвэл эвлүүлэлгүй бүтэн нэг үр дүнг
сонгоно. Хэцүү тохиолдолд хоёр дахь товч хэлээ албадан сонгох нөөц хэвээр.

### Үгчлэн ба цэгцэлсэн бичилт

**Бичилт → Үгчлэн бичих** асаалттай үед танигчийн эхний transcript утгын
өөрчлөлтгүй орно. «цэг» нь `.`, «хорин гурав» нь `23`, «буцаа» нь үйлдэл болохгүй;
яг тэр үгсээрээ бичигдэнэ. `auto_space` нь дараалсан сегментийг салгах оруулалтын
дүрэм тул тусдаа ажиллана. **Үгчлэн бичих цонх** жагсаалтад нэмсэн аппуудад энэ
горим автоматаар үйлчилнэ.

Цэгцэлсэн горим нь одоогийн цэвэрлэгээ, толь, нэр, тоо, дуут цэг таслал болон
дуут үйлдлийг ашиглана. Түүхийн мөр бүр raw transcript, эцсийн output, сонгосон
хэл, provider, confidence байгаа эсэх, горимыг хадгалдаг.

### Танигч солих

Таних хэсэг нь **залгуур** — «Яриа» хуудсан дээрх «Танигч» цэснээс сонгоно:

| Танигч | Юу шаардах | Тайлбар |
|---|---|---|
| **Google** (анхны утга) | юу ч шаардахгүй | Суулгамагц ажиллана. Дээрх хязгаарлалт үйлчилнэ |
| **Өөрийн үйлчилгээ** | хаяг + загвар + (заримд) түлхүүр | `POST …/v1/audio/transcriptions` бичиглэлтэй дурын үйлчилгээ эсвэл өөрийн компьютер дээрх сервер |

Хоёр дахь нь **OpenAI-нийцтэй** бичиглэл дээр тулгуурладаг тул нэг л танигчаар олон
өөр ард талд холбогдоно. Апп өөрөө сервер ажиллуулдаггүй, дундын түлхүүр
хадгалдаггүй — хэрэглэгч бүр өөрийн квот дээрээ сууна.

Хоёр ялгаа: тэр бичиглэл нь **олон хувилбар буцаадаггүй** тул толиор эргэж
сонгох ажиллахгүй, мөн **итгэлцэл өгдөггүй** тул «Итгэлцлийн босго» шүүлт
хийхгүй.

> ⚠️ API түлхүүр нь `%AppData%\Monspeech\config.json` дотор **ил** бичигдэнэ —
> апп нууц хадгалах сан ашигладаггүй. Хуваалцсан компьютер дээр анхаарна уу.

## Суулгах

### Энгийн хэрэглэгчид — `Monspeech.exe`

`Monspeech.exe` файлыг татаад давхар товш. Python, суулгац, бүртгэл юу ч
шаардахгүй — ганц файл, ~20 МБ. (Харьцуулбал Electron дээр хийсэн ижил төрлийн
апп 150–250 МБ байдаг.)

Анх ажиллуулахад тохиолдож болох зүйлс:

| Юу гарч ирэх | Яах вэ |
|---|---|
| **Windows protected your PC** (SmartScreen) | Гарын үсэг зурагдаагүй шинэ програм бүрт гардаг. **More info → Run anyway** |
| **Микрофон ашиглах зөвшөөрөл** | Зөвшөөрнө. Эс бөгөөс дуу сонсогдохгүй |
| Антивирус сэжиглэх | PyInstaller-ээр багцалсан програмд түгээмэл хуурамч дохио. Итгэмжлэгдсэн жагсаалтад нэмнэ |

Анх нээхэд **юунаас эхлэхийг гурван алхмаар** харуулна. «Ойлголоо» дарсны дараа
дахин гарахгүй.

Компьютер асахад автоматаар ажиллуулах бол цонхны **«Windows-тай хамт эхлүүлэх»**
чагтыг асаа. (Файлаа өөр газар зөөвөл чагт өөрөө унтарна — дахин асаахад шинэ
байрлал бүртгэгдэнэ.)

### Шинэчлэлт

Апп эхлэхдээ GitHub-аас шинэ хувилбар гарсан эсэхийг нэг удаа шалгана. Шинэ юм
байвал л мэдэгдэнэ — «Нэмэлт» хуудсанд «Шинэчлэл авах» товч гарч ирнэ.

Апп **өөрөө татаж солихгүй.** Гарын үсэг зурагдаагүй файлыг чимээгүйхэн солих нь
антивирусын ч, хэрэглэгчийн ч итгэх ёсгүй зан төлөв — тиймээс зөвхөн Releases
хуудас руу хүргэнэ.

Шалгалт нь GitHub рүү хүсэлт явуулдаг (IP хаяг харагдана) тул **Нэмэлт →
Шинэчлэл шалгах** гэсэн чагтаар унтраана.

**Устгах:** `Monspeech.exe`-г устга. Тохиргоо, түүхийг нь бүрэн арилгах бол
`%AppData%\Monspeech` хавтсыг устга.

### Хөгжүүлэгчид — эх кодоос

```bash
python -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt
```

Шаардлага: Windows, Python 3.11+, микрофон, интернэт холболт.

### `.exe`-г өөрөө бүтээх

```bash
powershell -NoProfile -File tools\build_exe.ps1
```

Үр дүн: `dist\Monspeech.exe`. Скрипт нь PyInstaller-ийг (`requirements-dev.txt`)
шаардлагатай үед өөрөө суулгана. Тохиргоо нь [tools/monspeech.spec](tools/monspeech.spec)
дотор — дүрсийг багцын дотор ижил замаар байрлуулж, pystray/pynput-ийн Windows
хэрэгжүүлэлтийг гараар зааж өгсөн (багцлагч өөрөө олдоггүй).

Логог солихдоо `assets\logo-source.png`-г шинэ зургаар сольж, `tools\make_icon.py`-г
ажиллуулна — `assets\monspeech.png` (1024 px) ба олон хэмжээт `assets\monspeech.ico`
шинэчлэгдэнэ.

Тушаалын мөрөөс:

```bash
.venv\Scripts\pythonw.exe -m monspeech
```

Дүрс дээр товшиход удирдлагын самбар шууд нээгдэнэ. Аль хэдийн ажиллаж байсан ч
дахин товшвол шинэ хуулбар нээхгүй — ажиллаж байгаа цонхыг урд нь гаргана.
Цонхыг хаахад апп tray-д (цагны хажууд) үлдэж ажиллана — сонсож байхад лого
өнгөтэй, амарч байхад бүдэг харагдана.
Компьютер асахад автоматаар ажиллуулахыг хүсвэл **«Windows-тай хамт эхлүүлэх»**
чагтыг асаа.

### Хэрэглээ

1. Текст оруулах цонхон дээрээ курсороо тавь.
2. **Windows + Alt-ыг дарж бариад** ярь — курсорын доор дууны долгион гарч ирнэ.
3. Товчоо тавь — текст курсор дээр орно.

Урт зүйл бичихэд **F9** дарж асаагаад чөлөөтэй ярь; өгүүлбэр бүр дуусмагц текст өөрөө
орсоор байна. Дуусахад дахин F9.

### Дуут командууд

| Хэлэх үг | Гарах тэмдэг |
|---|---|
| цэг | `.` |
| таслал | `,` |
| цэг таслал / хоёр цэг | `;` `:` |
| асуултын тэмдэг / анхаарлын тэмдэг | `?` `!` |
| гурван цэг / зураас / хашилт | `…` `-` `"` |
| хаалт нээх / хаалт хаах | `(` `)` |
| шинэ мөр / шинэ догол мөр | мөр таслах |

Англиар: `period, comma, question mark, new line, new paragraph` гэх мэт.

### Дуут үйлдэл

Цэг таслалаас ялгаатай нь эдгээр нь текст оруулахын оронд **үйлдэл гүйцэтгэнэ**.
Аюулгүйн үүднээс тухайн хэллэгийг **ганцаараа, бүтнээр нь** хэлсэн үед л
ажиллана — «энэ файлыг устга» гэж бичүүлэхэд текст устахгүй.

| Хэлэх үг | Юу болох |
|---|---|
| буцаа / устга / болих | Сүүлд оруулсан текстийг яг таг устгана |
| давт / давтаад бич / дахин бич | Сүүлийн текстийг дахин буулгана |
| хуулж ав / хуулаад ав | Сүүлийн текстийг clipboard руу (курсорт юу ч оруулахгүй) |
| зогс / бичихээ боль | Сонсохоо болино (F9-ийн үргэлжилсэн горимд) |

Англиар: `undo, scratch that, repeat that, copy that, stop recording`.

**Тоо нэмж болно**: «хоёр удаа буцаа», «гурав давт» — буцаах ба давтах хоёр нь
99 хүртэл давталт хүлээж авна («хоёр» гэж үгээр хэлсэн ч ойлгоно).

**Өөрийн хэллэг нэмэх**: **Толь → Дуут үйлдэл** дээр зүүн талд хэлэх үгээ,
баруун талд `буцаах`, `давтах`, `хуулах`, `зогсоох`-ийн аль нэгийг бичнэ.
Дотор нь суусан хэллэгүүд үүнээс үл хамаарч ажиллаж байх болно.

### Сүүлийн бичвэрүүд

Роботын доор хамгийн сүүлийн 5 бичвэр өдрөөр бүлэглэгдэн харагдана — ярьсныхаа
дараа «юу орсон бэ?» гэдгийг хуудас солихгүйгээр шалгана. Мөр дээр хулгана
хүргэхэд гурван үйлдэл гарч ирнэ:

| Дүрс | Юу болох |
|---|---|
| ▷ | Дахин буулгах — 2 секундын дотор курсороо тавина |
| ⧉ | Clipboard руу хуулах (курсорт юу ч оруулахгүй) |
| ✎ | Засах — ялгааг нь Толь руу автоматаар сурна |

Хулганагүйгээр ч ажиллана: Tab-аар мөр рүү очоод Enter дарвал дахин буулгана.
Бүтэн жагсаалт, хайлт, хэл батлах зэрэг нь **Түүх** хуудсанд байна.

### Дуут засвар

Команд горим (эсвэл энгийн бичилт) дунд сүүлийн оруулгаа дуугаар засна:

| Хэлэх үг | Юу болох |
|---|---|
| үг устга / сүүлийн гурван үгийг устга | Төгсгөлөөс нь N үг арилгана |
| том үсэг болго / жижиг үсэг болго | Сүүлийн үгийн эхний үсгийг солино |
| зайг ав | Төгсгөлийн зайг устгана (цэг таслал наахад) |
| **оронд нь ‹үг›** | Сүүлийн үгийг солино — **зөвхөн команд горимд** |

Англиар: `delete last 2 words`, `capitalize that`, `lowercase that`, `no space`.

Сүүлийн заавар нь чөлөөт текст авдаг тул энгийн бичилтэд ажиллуулахгүй —
«оронд нь маргааш уулзъя» гэж ярихад текст засагдвал төөрөгдөл үүснэ.

### Файлаас хөрвүүлэх

**Хөрвүүлэх → Файл сонгох** дээрээс аудио/видео файл сонгоно. Яриаг чимээгүй
завсраар нь хэсэглээд дараалан илгээх тул урт бичлэг ч ажиллана; явц нь
цонхонд харагдана. Үр дүн нь:

* эх файлын хажууд `.txt` болж хадгалагдана,
* мөр бүр Түүхэнд нэмэгдэнэ (хайлт, толь сурах хоёр тэндээс ажиллана).

**WAV** файл нэмэлт хэрэгсэлгүй ажиллана. MP3, M4A, MP4 зэрэгт `ffmpeg`
шаардлагатай — байхгүй бол цонх тэр тухай хэлнэ.

### Системийн дуу (онлайн хурал)

Микрофоны жагсаалтаас **«Чанга яригч · …»** сонгоход микрофоны оронд
компьютерийн тоглуулж буй дуу бичигдэнэ — Zoom, Teams, YouTube. Windows-ийн
WASAPI loopback ашиглана (`pyaudiowpatch`); тэр сан байхгүй бол энэ сонголт
зүгээр л харагдахгүй, апп хэвийн ажиллана.

Төхөөрөмжийн эх формат (ихэвчлэн 48 кГц, стерео) руу нь нээгээд, дамжлагын
16 кГц моно руу өөрөө хөрвүүлнэ.

### Команд горим

Дуут үйлдлүүд энгийн бичилтэд ч ажилладаг тул «зогс» гэж жинхэнэ бичүүлэх үед
команд болж хувирах эрсдэлтэй. **Win + Ctrl**-ыг дарж барин ярьвал хэлсэн зүйл
**огт текст болохгүй** — зөвхөн үйлдэл гүйцэтгэнэ. Танихгүй бол «Танихгүй
команд: «…»» гэж юу сонссоноо хэлнэ, түүх ч бохирдохгүй.

### Хувилбар сонгох ба сэлгэх

Танигч нэг таналтад **8 хүртэл** хувилбар буцаадаг — бүгд нэг хариунд ирдэг тул
нэмэлт хүсэлт, саатал, төлбөр үүсэхгүй. Өмнө нь зөвхөн эхнийх нь ашиглагдаж,
үлдсэн нь хаягддаг байв.

Аль нь зөв болохыг гурван шатлалаар шийднэ — дээд шат нь шийдвэл доод шат руу
огт очихгүй:

1. **Чиний өөрийн бичсэн зүйл** — толь, дуут товчлол, нэрс. Толиндоо
   «клауд = Claude» гэж нэмсэн бол хувилбар #4 нь «клауд» байсан ч тэр гарна.
2. **Өөрийн ярианаас сурсан загвар** — өмнөх бүх өгүүлбэрээс үгийн хос тоолсон
   локал загвар. «хурал дээрээ» vs «хурал дээр ээ» гэх бичиглэлийн зөрүүг
   зөвхөн энэ ялгана. Түүхэн дэх ~200 үгээс эхлэн ажиллана, диск дээр юу ч
   нэмэхгүй (апп нээхдээ түүхээсээ 11 мс-д босгодог).
3. **Түүхэнд тааралдсан үг** — загвар хараахан сураагүй байхад ажиллах нөөц зам.

Нотолгоо олдохгүй бол танигчийн эрэмбэ хэвээр — эргэлзвэл хөндөхгүй.

Эхний сонголт буруу байвал **Ctrl + Alt + Space** дарахад:

1. Оруулсан текст яг таг устаж, дараагийн хувилбар орно
2. Түүхэн дэх мөр ч шинэчлэгдэнэ
3. Сонгосон хувилбар **толинд өөрөө сурагдана** (Засварыг сурах асаалттай бол)
   — дараа нь ижил үг зөв гарна

Дахин дарвал дараагийнх руу, төгсгөлд нь эхнийхэд эргэж ирнэ. Хэрэв энэ
хооронд гараараа өөр зүйл бичсэн бол сэлгэхээ болино — буруу тэмдэгт устгахгүй.

### Товчны өмнөх дуу

Хүн товчоо дараад ярьдаггүй — ярьж эхлээд дардаг. Микрофон бэлэн байх зуур
уншсан дууг хаялгүй богино цагираг буферт хурааж, товч дармагц бичлэгийн эхэнд
залгана. **Нэмэлт → Товчны өмнөх дуу** (анхдагч 0.6 сек, 0 бол болино).

Буферт бүтэн өгүүлбэр (яриа + завсарлага) багтсан бол түүнийг хаяна — товч
дарахаас өмнө дууссан яриа энэ бичлэгт хамаарахгүй.

### Толиор дохио өгөх

Whisper-төрлийн үйлчилгээ (OpenAI-нийцтэй танигч) нь `prompt` талбарт өгсөн
үгсийг таних магадлалыг өсгөдөг. **Яриа → Толиор дохио өгөх** асаалттай үед
хэрэглэгчийн **нэрс ба толийн зөв тал** тэр талбараар дамжина: «Чимэгсайхан»
гэдэг нэр дараа нь солигдох биш, ЭХНЭЭСЭЭ зөв ирнэ.

Урт нь ~450 тэмдэгтээр хязгаарлагдана (үйлчилгээний хязгаарт багтаах);
нэрс эхэлж, дараа нь толийн зөв тал орно. Google танигчид нөлөөгүй.

### Чимээ дарах

Илгээхийн өмнө хоёр зүйл хийнэ (офлайн, 2 секунд дуунд ~12 мс):

1. **Доод давтамж таслах** — сэнс, кондиционер, ширээний цохилт (50 Гц-ийг
   ~12 дБ-ээр дарж, 1 кГц ярианы давтамжийг бараг хөндөхгүй),
2. **Чимээний хаалт** — ярианы хоорондох тогтмол хишиг, шуугианыг сулруулна.
   Чимээний түвшинг бичлэгийн хамгийн намуухан хэсгээс хэмждэг тул орчин
   бүрд өөрөө тохирно.

**Яриа → Чимээ дарах** гэсэн чагтаар унтраана.

### Ярианы илрүүлэгч

Апп «хэзээ өгүүлбэр дууссан бэ» гэдгийг мэдэх ёстой — тэр цэг дээр дууг
илгээдэг. Өмнө нь үүнийг зөвхөн дууны ТҮВШИНгээр шийддэг байсан: «босгоос
чанга бол яриа». Түвшин нь ярианы шинжийг хэмждэггүй тул хоёр талаас нь алддаг:

- гар товчлуурын товшилт, цаасны чимээ босго давдаг тул сегмент төгсдөггүй;
- аяархан хэлсэн үг, өгүүлбэрийн сүүлийн үе («…юм», «…уу») босго давахгүй тул
  **тайрагддаг**. Энэ нь илүү үнэтэй: тайрагдсан үг танигчид огт хүрэхгүй тул
  засах ямар ч боломж үлдэхгүй.

Одоо WebRTC-ийн ярианы илрүүлэгч давтамжийн бүтцээр шийднэ (Chrome, Meet, Zoom
бүгд үүнийг ашигладаг). 20 мс тутамд шалгаж, уншилтын гуравны нэг нь яриа бол
уншилт бүхэлдээ яриа — үгийн эхлэл тайрагдахгүй байх нь чухал.

**Яриа → Ярианы илрүүлэгч** гэсэн чагтаар унтраана (тэр үед хуучин зам буюу
дууны түвшин ажиллана). `webrtcvad` сан суугаагүй бол чагтаас үл хамааран
түвшингийн зам ажиллана — апп ямар ч тохиолдолд ажиллана.

### Чигчлүүр цэвэрлэх

Ярьж байгаа хүн бичиж байгаа хүн шиг ярьдаггүй. Аппад **Бичилт → Чигчлүүр
цэвэрлэх** гэсэн чагт байгаа (анхнаасаа асаалттай):

| Хэлсэн | Орох текст |
|---|---|
| «ааа маргааш уулзъя» | Маргааш уулзъя |
| «за тэгээд ажил эхэллээ» | Ажил эхэллээ |
| «би би би явлаа» | Би явлаа |
| «5 цагт **үгүй ээ** 6 цагт» | 6 цагт |

Эргэлзвэл хөндөхгүй гэсэн зарчмаар хийсэн тул дараах зүйлсийг **хэзээ ч
хасахгүй**:

- **Жинхэнэ бөөмүүд**: «байна **уу**», «мөн **үү**», «тийм **ээ**» — эдгээр нь
  чимээ биш, утга агуулдаг
- **Өгүүлбэр дунд байгаа «за», «тэгээд»** — «уулзаад тэгээд яръя» хэвээрээ
  үлдэнэ. Зөвхөн өгүүлбэрийн эхнээс хасна
- **Дан «үгүй», «биш»** — «тийм үү үгүй юу» гэдгийг засвар гэж үзэхгүй. Зөвхөн
  бүтэн «үгүй ээ», «биш ээ» хоёр үгийг тэмдэг гэж таньдаг
- **Иш татсан үг** — «за гэж хэлээд явлаа» хэвээрээ. Араас нь «гэж», «гэсэн»,
  «гээд» ирвэл тэр нь чигчлүүр биш, иш татсан үг
- **Чангатгах давталт** — «маш маш сайн» хэвээрээ

Засвар олдвол зөвхөн сүүлийн цэг таслалын дараах хэсгийг хаяна — «би явлаа **цэг**
5 цагт үгүй ээ 6 цагт» гэвэл эхний өгүүлбэр бүрэн үлдэнэ.

Тодорхой цонхонд **үгчлэн** бичүүлэх шаардлагатай бол (эш татах, ярианы
тэмдэглэл) тэр цонхонд нэг удаа бичүүлээд **Бичилт → Цэвэрлэхгүй цонх →
Сүүлийн цонхыг нэмэх** дээр товш. Ерөнхий чагт асаалттай хэвээр байх ба зөвхөн
тэр цонхонд цэвэрлэгээ хүчингүй болно.

### Тоог цифрээр

**Бичилт → Тоог цифрээр** (анхнаасаа асаалттай). Монгол тоо нэрийн бүтэц бол
энгийн нэмэх/үржих дүрэм тул LLM хэрэггүй:

| Хэлсэн | Орох текст |
|---|---|
| «хорин гурван цагт» | 23 цагт |
| «хоёр мянга хорин зургаан он» | 2026 он |
| «мянга есөн зуун ерэн зургаа» | 1996 |
| «дөрвөн цаг гучин минут» | 4 цаг 30 минут |

Энд ч мөн **эргэлзвэл хөндөхгүй**:

- **Ганцаараа өдөр тутмын утгатай үгс** — «**ер** нь», «**сая** хэлсэн», «**нэг**
  л удаа», «**тав** тухтай» хэвээрээ. Хоёр ба түүнээс дээш тооны үг дараалбал л
  эргэлзээгүй тоо гэж үзнэ («хорин нэг» → 21)
- **Тооны бүтэц биш цуваа** — «нэг хоёр гурав» гэж тоолж байгааг 6 болгохгүй.
  Жинхэнэ тоонд нэмэгдэхүүн бүр өмнөхөөсөө жижиг байдаг
- **Дэс тоо** — «хорин **нэгдүгээр** зуун» гэдгийн «хорин» нь 20 биш, 21-ийн
  хагас тул хөндөхгүй

### Нэрсийн толь

**Толь → Нэрс** дээр зөвхөн **зөв нэрээ** бичнэ. Танигч нэрийг тогтмол нэг янзаар
буруу сонсдоггүй тул хувилбар бүрд мөр нэмэх нь эцэс төгсгөлгүй — иймд нэрийг
ойролцоо зайгаар (засварын зай) тааруулна:

| Сонсогдсон | Орох текст |
|---|---|
| «чимэгсайхан» | Чимэгсайхан |
| «чимэг сайхан» (хоёр үг болж хуваагдсан) | Чимэгсайхан |
| «чимэгсайхны» | Чимэгсайханы |
| «чимэгсайхантай» | Чимэгсайхантай |

Хол зөрдөг хувилбарыг баруун талд таслалаар тусгаарлан нэмнэ (жишээ нь «чимээ
сайхан»). **6 үсгээс богино нэр зөвхөн яг таг таарвал** солигдоно: «Болд» гэх
богино нэр нь «болно», «болж» гэсэн өдөр тутмын үгнээс ганц үсгээр зөрдөг тул
ойролцоо тааруулбал хэвийн яриа нэр болж эхэлнэ. Нэрс нь хувилбар сонголтод ч
жин болно — танигчийн буцаасан хувилбаруудаас нэр агуулсныг нь эхнээс нь сонгоно.

### Тохиргооны цонх

Үндсэн цонх нь **зүүн талын цэс, баруун талд солигддог 6 хуудас** (1280 × 840 px).
Цэсний толгойд аппын лого том байрлана; доод талд нь «Тохиргоо» ба «Алдаа
мэдээлэх», хамгийн доод мөрөнд төлөв ба хумих товч.

| Цэс | Агуулга |
|---|---|
| **Төлөв** | Робот (Бэлэн / Сонсож байна / Таниж байна), хэл хурдан солих, сүүлийн бичвэрүүд |
| **Толь** | Үг солих, нэрс, дуут товчлол, аппын хэл, дуут үйлдэл — мөр мөрөөр нь засварладаг жагсаалт |
| **Түүх** | Таньсан текстүүд, хайлттай, давхар товшвол дахин буулгана |
| **Хөрвүүлэх** | Хурлын бичлэг, лекц, дуут тэмдэглэлийг текст болгоно — үр дүн нь эх файлын хажууд .txt болж хадгалагдана |
| **Хэрэглээ** | Үг/минут, толийн дүрэм, нийт үг — дээр нь сүүлийн 7 өдрийн багана график ба тасралтын халив (GitHub commit-ийн хэв маяг) |
| **Аппууд** | Цонх бүрийн дүрэм нэг дор: хэл, шууд бичих, цэвэрлэхгүй — сүүлд бичсэн цонхонд шууд тохируулж, дүрэмтэй аппуудаа жагсаалтаас нь устгана |

**«Тохиргоо» цэс рүү товшвол тусдаа цонх давхаргарч ирнэ** — өдөр бүр биш,
тохируулах үедээ л нээгддэг зүйлс бүгд тэнд төвлөрнө. Зүүн талд нь хэсгүүд,
баруун талд нь агуулга:

| Хэсэг | Агуулга |
|---|---|
| **Яриа** | Үндсэн хэл, хоёр дахь хэл, микрофон (чанга яригч ч), оролтын түвшин, хэл автоматаар таних, чимээ дарах, толиор дохио өгөх, хэрэглээ ба зардал, танигч сонгох |
| **Бичилт** | Шууд бичих, зай нэмэх, том үсгээр эхлүүлэх, дуут цэг таслал, тоог цифрээр, чигчлүүр цэвэрлэх, цонхны үл хамаарах зүйлс — тохиргоо солих бүрт үр дүн нь тэр дороо жишээ болж харагдана |
| **Товчлуур** | 6 товчлуур тус бүр «Солих» товчтой |
| **Нэмэлт** | Горим, гулсуурт тохируулга, өнгөний сэдэв, систем, хувилбар ба шинэчлэлт, алдаа мэдээлэх |

Товчлол: **Ctrl+1…6** — үндсэн цэс сонгох. Цонхыг нарийсгавал цэс өөрөө дүрс болж
хумигдана (доод талын товчоор ч болно).

Нарийн тохируулга («Нэмэлт» цэсэнд гулсуураар):

| Тохиргоо | Утга |
|---|---|
| Завсарлага | Хэдэн секунд чимээгүй байвал өгүүлбэр дууссан гэж үзэх (0.4–1.2) |
| Итгэлцлийн босго | Үүнээс доош итгэлцэлтэй үр дүнг оруулахгүй (0 = шүүхгүй) |
| Микрофон бэлэн барих | Бичлэгийн дараа микрофоныг хэдэн секунд нээлттэй барих |
| Бичлэгийн дээд хугацаа | Товч гацсан ч энэ хугацааны дараа бичлэг өөрөө зогсоно |

**Хоёр дахь хэл**: Win+Shift дарахад ямар хэлээр бичихийг «Яриа» цэснээс
сонгоно (анхны утга English).

- **Товчлуур**: `<cmd>+<alt>` (Win+Alt), `<f8>`, `<ctrl>+<shift>+m` гэх мэт бичиглэл.
  `<cmd>` нь Windows товчийг заана.
- **Clipboard-гүйгээр шууд бичих**: зарим апп синтетик Ctrl+V-г хүлээж авдаггүй. Тэр
  тохиолдолд энэ горимыг асаа (арай удаан, гэхдээ clipboard-ыг огт хөндөхгүй).
  Бүх аппад биш, зөвхөн тэр нэг цонхонд хэрэглэхийг хүсвэл: тэр цонхонд нэг удаа
  бичүүлээд, дараа нь **Бичилт → Сүүлийн цонхыг нэмэх** дээр товш. Цаашид зөвхөн тэр
  цонхонд шууд бичих горим ажиллана.

**Толь → Үг солих** дээр мөр бүрт «буруу таньсан → зөв бичих» гэсэн хоёр талбар:
`клауд → Claude`. «Мөр нэмэх» дээр товшиж нэмнэ, ✕ дээр товшиж устгана
(диск дээр `буруу=зөв` хэлбэрээр хадгалагдана).

Бүх тохиргоо `%AppData%\Monspeech\config.json` дотор хадгалагдана.

## Судалж үзээд хассан хувилбарууд

Бусад аппуудыг судалж, дараах гурвыг **энэ компьютер дээр хэмжиж үзээд** хассан:

| Хувилбар | Яагаад хассан |
|---|---|
| Chimege, Echo STT (монгол хэлний API) | Төлбөртэй — Chimege 15₮/15 сек, Echo 35–45₮/мин |

Тиймээс үнэгүй бөгөөс бодитоор ажиллах цорын ганц хөдөлгүүр нь Google Web Speech
хэвээр байна. Хүчирхэг видео карттай машин дээр локал Whisper дахин боломжтой болно.

## Асуудал гарвал

Апп бүх алхмаа `%AppData%\Monspeech\monspeech.log` дотор тэмдэглэдэг (**Нэмэлт →
Логийн хавтас**). Таньсан текстийг бүтнээр нь бичихгүй — зөвхөн урт, итгэлцэл,
хугацаа. Юу болсныг эргэж харахад хангалттай.

**Алдаа мэдээлэх:** **Нэмэлт → Мэдээлэл хуулах** дарвал хувилбар, Windows-ийн
хувилбар, танигч, хэл, микрофоны дугаар, толийн хэмжээ clipboard-д орно — үүнийг
асуултдаа хавсаргана. Ярианы текст, API түлхүүр **орохгүй**, микрофоны нэр ч
орохгүй (хүний нэр агуулж мэднэ) тул хэн нэгэнд шууд явуулж болно.

Баригдаагүй алдаа гарвал ч чимээгүй үхэхгүй: `.exe`-д консол байхгүй тул
стандарт зан төлөв нь алдааг хаашаа ч бичихгүйгээр залгидаг. Одоо гол thread,
ажлын thread, цонхны callback гурвуулангийн алдаа лог руу бичигдэнэ.

Апп чимээгүй бүтэлгүйтэхгүй: микрофон салах, дуу сонсогдохгүй байх, итгэлтэй таньж
чадахгүй байх бүрд төлвийн мөр болон курсорын доорх заалтад шалтгааныг харуулна.
Товч суллах эвент алдагдвал секунд тутмын шалгалт үүнийг илрүүлж бичлэгийг зогсооно.

## Техникийн тэмдэглэл

Windows дээр гацуулж мэдэх зүйлсийг тусгайлан шийдсэн:

1. **Кирилл гарын layout дээр Ctrl+V.** Тэмдэгтээр (`"v"`) илгээвэл pynput нь Unicode
   оролт болгодог бөгөөд Ctrl-тэй хослохгүй — зүгээр л "v" бичигддэг. Иймд виртуал
   товчийн код (`0x56`) ашигладаг.
2. **Товчлуурын hook-оос Tk рүү хандах.** Hook thread-ээс `root.after` дуудвал Tcl
   түгжээнд саатаж, Windows дараагийн товчлуурын эвентийг хаядаг → товчлуур гацдаг.
   Иймд бүх эвент дарааллаар (queue) дамжина.
3. **Текст очих цонх.** Товч дарсан агшны цонхыг тогтоож аваад, буулгахын өмнө
   идэвхтэй эсэхийг шалгаж, шаардвал буцаан идэвхжүүлдэг.
4. **Дараалал.** Таних ба буулгах ажил нэг ээлжийн worker дээр явдаг тул өгүүлбэрүүд
   хэзээ ч эргэж холилдохгүй.
5. **Win/Alt-ыг дангаар нь суллах.** Alt-ыг өөр товчгүйгээр тавихад Win32 аппын цэсийн
   мөр идэвхжиж, дараагийн Ctrl+V-г залгидаг (текст алга болно); Win-ийг дангаар тавихад
   Start цэс нээгддэг. Иймд хослол ажиллах агшинд тодорхойлогдоогүй виртуал товч (0x07)
   илгээж, тэр даралтыг "ашиглагдсан" болгодог. Хэмжсэн: хамгаалалтгүй үед текст
   огт ордоггүй, хамгаалалттай үед найдвартай ордог.
6. **Микрофоны бэлэн байдал.** Урсгалыг хаагаад дахин нээхэд эхний дуу ирэх хүртэл
   ~0.8 сек болдог (`stop_stream`/`start_stream` ч мөн адил). Зөвхөн урсгалыг
   тасралтгүй ажиллуулж байж 0 мс болдог тул бичлэгийн дараа богино хугацаанд
   нээлттэй барьж, хоосон хэсгийг нь хаядаг.
7. **Долгионы цонх.** `WS_EX_NOACTIVATE | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW` хэв
   маягтай тул фокус авахгүй, товшилтыг доогуураа дамжуулна, alt-tab-д гарахгүй.
   Байрлалыг `GetGUIThreadInfo`-оор текстийн курсорноос авах ба өгөхгүй апп дээр
   (Chrome, UWP) хулганы байрлал руу шилжинэ.
8. **Орчны чимээний хэмжилт.** Эхний 0.25 секундээр босго тогтоодог. Хэрэглэгч товч
   дармагцаа ярьвал хэмжилт нь ЯРИАН дээр тохирч, босго 14000 хүрч, бүх яриаг
   "чимээгүй" гэж үзэн чимээгүйгээр хаядаг байсан. Одоо босгод дээд хязгаар тавьж,
   яриа удаан олдохгүй байвал ажигласан дууны түвшнээс автоматаар дахин тогтооно.
9. **Админ эрхтэй цонх.** Windows-ийн UIPI нь бага эрхтэй процессоос өндөр эрхтэй
   цонх руу оролт илгээхийг хаадаг тул текст чимээгүйгээр ордоггүй. Бичиж эхлэхэд
   зорилтот цонхыг шалгаж, ийм тохиолдолд урьдчилан анхааруулна.
10. **Нууцлал ба Аюулгүй байдал (DPAPI).** Хэрэглэгчийн `stt_key` API түлхүүр нь `config.json` дотор ил текстээр биш, Windows-ийн CryptProtectData (DPAPI)-гаар шифрлэгдэн `dpapi:…` хэлбэрээр хадгалагдана. Хэрэглэгчийн Windows нууц үгээр шифрлэгддэг тул өөр компьютер эсвэл өөр хэрэглэгч файлыг нээхэд тайлагдахгүй.
11. **Google Web Speech эрсдэл.** Анхны Google танигч нь Chromium-ийн задгай API түлхүүрийг ашигладаг (түлхүүргүй, үнэгүй). Нийт ачаалал ихсэх үед Google-ээс 429/403 хариу өгч түр тасалдаж болох бөгөөд тийм үед «Яриа» хуудсанаас өөрийн OpenAI-нийцтэй түлхүүрийг шилжүүлэн тохируулах боломжтой.
12. **Олон дэлгэц.** Tk-ийн `winfo_screenwidth` нь зөвхөн үндсэн дэлгэцийг мэддэг тул
   заалт хоёр дахь дэлгэц рүү гардаггүй байсан. Одоо `MonitorFromPoint` +
   `GetMonitorInfo`-оор курсор байгаа дэлгэцийн ажлын талбайг авч, цонхыг Tk-ийн
   `geometry`-ийн оронд `SetWindowPos`-оор байрлуулна (Tk сөрөг координатыг "баруун
   захаас" гэж ойлгодог тул зүүн талын дэлгэц дээр эвдэрдэг).
11. **Хэд хэдэн хувилбараас сонгох.** Таних үйлчилгээ нэг хэлсэн зүйлд гурван
   хувилбар буцаадаг (`maxAlternatives`). Өмнө нь зөвхөн эхнийхийг нь авч үлдсэнийг
   нь хаядаг байсан — өөрөөр хэлбэл чанар сайжруулах өгөгдөл хариунд ирчихээд
   ашиглагдалгүй хаягдаж байв. Одоо хэрэглэгчийн **толь ба дуут товчлолд** хамгийн
   сайн нийцэх хувилбарыг сонгоно: «клауд=Claude» гэж нэмсэн хүнд эхний хувилбар нь
   «клоуд» гараад хоёр дахь нь «клауд» байвал хоёр дахийг нь авна. Нэмэлт хүсэлт,
   саатал, төлбөр үүсэхгүй. Дуут командыг санаатай оноололд оруулаагүй — «цэг» гэж
   сонсогдсон бүхнийг дэвшүүлбэл жинхэнэ үгийг цэг болгож гээх эрсдэлтэй. Оноо
   тэнцвэл үйлчилгээний эрэмбэ хэвээр үлдэнэ.
12. **Микрофоны дугаар тогтвортой биш.** PyAudio нь төхөөрөмжийг дугаараар нь
   өгдөг ба тэр дугаар нь чихэвч салгаж холбоход шилждэг. Хуучирсан дугаараар
   нээхэд PortAudio «Invalid number of channels» (-9998) гэж шиднэ — сонсох суваг
   нь тэг учраас. Ганц микрофон нь Bluetooth чихэвч бол салах үед MME-ийн
   «Microsoft Sound Mapper - Input» хүртэл ийм болдог. Иймд микрофоныг дугаар БА
   нэрээр нь санаж, нээх бүрд одоогийн жагсаалттай тааруулна: нэрээр нь олдвол
   тэр дугаар, олдохгүй ч хадгалсан дугаар нь сонссоор байвал хэвээр (Windows нь
   төхөөрөмжийн нэрийг өөрчилдөг), аль нь ч биш бол системийн үндсэн рүү.
   Сонгосон микрофоны оронд өөр төхөөрөмж нээгдвэл дуугүй өнгөрөхгүй — цонх ба
   заалтад хэлнэ. Мөн нэг физик микрофон MME/DirectSound/WASAPI-аар давхар гардаг
   тул жагсаалтад нэг л удаа гарна.

## Түгээмэл асуудал

- **"Микрофон нээгдсэнгүй"** — Windows Тохиргоо → Нууцлал → Микрофон дээр зөвшөөрөл өг,
  эсвэл цонхноос өөр төхөөрөмж сонго.
- **Юу ч танигдахгүй байна** — чанга ярь; дууны түвшний зураас хөдөлж байгаа эсэхийг хар.
- **"403" / "429"** — задгай эндпойнтын хязгаарлалт; хэсэг хүлээгээд дахин үзнэ үү.
- **Текст ороогүй** — тухайн апп синтетик Ctrl+V-г хүлээж авдаггүй байж болно;
  "Clipboard-гүйгээр шууд бичих" горимыг туршиж үз.
- **Монгол хэл тааруу таньж байна** — Google-ийн `mn-MN` загварын чанараас шалтгаална;
  тод ярих, чанартай микрофон ашиглах, давтагддаг алдааг "Үг солих" толинд нэмэх нь тусална.
